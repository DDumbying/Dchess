# Puzzles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A puzzles mode (Rated, Themes, Rush, Missed) from a bundled Lichess set, with the rating and streak kept per profile.

**Architecture:**
- `tools/mkpuzzles.c` writes the compiled-in `src/game/puzzles_data.c`.
- `game/puzzles.c` holds the rules, and `game/puzzle_stats.c` the rating, selection and storage. Neither uses ncurses.
- `tui/puzzles_tui.c` draws the menu and runs the modes on the existing `Screen`.

**Tech Stack:** C, `make test`, tmux for the smoke test.

**Spec:** `docs/superpowers/specs/2026-09-28-puzzles-design.md`

> Terse by request. The spec holds the behaviour; this plan holds names, order and tests.

## Global Constraints

- Zero warnings. `game/` stays free of ncurses. Sparse comments. No attribution trailers.
- Every existing suite passes after each task; `make -B test` ends with "All suites passed."
- Puzzle files live in `$HOME/.local/share/dchess/puzzles/<profile>.txt`; guests save nothing.
- Keys: `?` hint, `s` show, `n` next, `r` retry, `esc` back; `z` opens puzzles from the launcher; the CLI flag is `--puzzles`.

## Interfaces (all tasks)

```c
/* headers/game/puzzles.h */
enum { TH_MATE1 = 1 << 0, TH_MATE2 = 1 << 1, TH_MATE3 = 1 << 2, TH_MATE = 1 << 3, TH_FORK = 1 << 4,
       TH_PIN = 1 << 5, TH_SKEWER = 1 << 6, TH_DISCOVERED = 1 << 7, TH_HANGING = 1 << 8,
       TH_SACRIFICE = 1 << 9, TH_ENDGAME = 1 << 10, TH_PROMOTION = 1 << 11, TH_BACKRANK = 1 << 12,
       TH_DEFENSIVE = 1 << 13, TH_BITS = 14 };
#define PUZZLE_MAX 4096
#define PUZZLE_PLIES 8
typedef struct { const char *id, *fen, *moves; short rating; unsigned short themes; } PuzzleData;
extern const PuzzleData puzzle_data[];            /* sorted by rating */
extern const int puzzle_count;
const char *puzzle_theme_name(int bit);           /* "mate in 1", "fork", … */
int  puzzle_find(const char *id);                 /* index or -1 */

typedef enum { PZ_WRONG, PZ_RIGHT, PZ_SOLVED } PuzzleVerdict;
typedef struct { int index; Move line[PUZZLE_PLIES]; int len, next, failed, done; } Puzzle;
int  puzzle_start(Puzzle *p, int index, GameState *g);   /* FEN + the opponent's first move */
PuzzleVerdict puzzle_try(Puzzle *p, GameState *g, Move m);  /* WRONG leaves g unchanged */
int  puzzle_hint(Puzzle *p);                             /* the from-square; marks failed */
int  puzzle_show_step(Puzzle *p, GameState *g);          /* plays one move; 0 once done */

/* headers/game/puzzle_stats.h */
typedef struct { int rating, played, streak, best_streak, rush_best;
                 unsigned char seen[PUZZLE_MAX]; int missed[PUZZLE_MAX], nmissed; } PuzzleStats;
void puzzle_stats_init(PuzzleStats *s);                  /* 1500, empty */
int  puzzle_stats_dir(char *buf, size_t n);              /* creates it */
int  puzzle_stats_load(const char *dir, const char *profile, PuzzleStats *s);  /* 0: defaults */
int  puzzle_stats_save(const char *dir, const char *profile, const PuzzleStats *s);
int  puzzle_stats_rename(const char *dir, const char *from, const char *to);
int  puzzle_stats_remove(const char *dir, const char *profile);
int  puzzle_rating_after(int rating, int played, int puzzle_rating, int solved);
void puzzle_stats_record(PuzzleStats *s, int index, int solved);  /* a rated result */
void puzzle_stats_forgive(PuzzleStats *s, int index);            /* a solve outside Rated */
int  puzzle_pick(unsigned char seen[PUZZLE_MAX], int target, unsigned themes, unsigned *seed);

/* headers/game/replay.h: find_san made public */
Move replay_find_san(const GameState *g, const char *tok);

/* headers/tui/puzzles_tui.h */
typedef enum { PM_RATED, PM_THEMES, PM_RUSH, PM_MISSED } PuzzleMode;
typedef struct PuzzleView { PuzzleMode mode; Puzzle pz; int rating, delta, streak, score, strikes;
                            long rush_left_ms; int verdict, hint_sq, wrong_from, wrong_to; } PuzzleView;
int puzzles_screen(TUIState *s);                         /* the menu; returns on esc */

/* headers/tui/tui.h */
struct PuzzleView;                  /* TUIState gains: const struct PuzzleView *puzzle; */
int tui_cursor_key(TUIState *s, int ch, Move *out);  /* cursor keys; 1 when Enter picked a move */
```

## Review Focus

1. **Promotions in a solution** (`e7e8q`): the move matches, even when the cursor chose one without a promotion piece. Task 2 test (a promotion puzzle, entered with the promotion given and without it).
2. **A mate that differs from the stored one on a non-final move:** it is accepted only when it mates (so the puzzle ends solved), never as a "right" middle move. Task 2 test.
3. **The profile's file damaged, or naming puzzles no longer bundled:** it loads without a crash; unknown ids are dropped, and bad lines are skipped. Task 3 test.
4. **Every puzzle of a theme or window already seen:** `puzzle_pick` resets that subset and still returns one; it never loops forever or returns −1 while puzzles exist. Task 3 test.
5. **A terminal resize, and Rush's clock running out mid-move:** no stale window (re-fetch `tui_screen_input` each loop), and the run ends at 0 with the score saved. Task 4 smoke test.

### Task 2: The rules

**Files:** Modify `src/game/puzzles.c`, `headers/game/puzzles.h`, `src/game/replay.c` (`find_san` → public `replay_find_san`), `headers/game/replay.h`, `tests/test_puzzles.c`.

- [ ] **Step 1: Tests** (rules section), each on a real bundled puzzle found by theme:
  - After `puzzle_start`, it is the solver's turn, one ply has been played, and `next == 1`.
  - `puzzle_try` with the solution move gives `PZ_RIGHT` (or `PZ_SOLVED` on the last), and the reply has been played.
  - A wrong legal move gives `PZ_WRONG`, `failed` is set, and the position hash is unchanged.
  - A different mating move is accepted: search `puzzle_data` for a mate-in-1 where more than one legal move mates (use `generate_moves`, and count the mates), play the other mate, and get `PZ_SOLVED`. If none exists, print a note and skip.
  - A mating move that is not the solution, played before the last step, gives `PZ_SOLVED` (it ends the game).
  - `puzzle_hint` returns `FROM(line[next])` and sets `failed`.
  - `puzzle_show_step` plays to the end and returns 0 once done.
  - A promotion puzzle (`TH_PROMOTION` with a promoting solution) is accepted both with the promotion piece and when the move is given with promo 0 (take the queen).
- [ ] **Step 2:** Run `./build/test_puzzles`. Expected: FAIL (undefined `puzzle_start`).
- [ ] **Step 3:** Implement:
  - parse `moves` into `line` against a scratch `GameState`;
  - a move matches when the from/to match and the promotion is equal, or the given promotion is 0 and the stored one is a queen;
  - a mate test on a copy after `game_play` (`game_update_status` → `game_over` and "Checkmate").
- [ ] **Step 4:** Run `make -B test`. Expected: all pass. Commit `feat(puzzles): judging moves against the solution`.

### Task 3: The rating, selection and storage

**Files:** Create `headers/game/puzzle_stats.h`, `src/game/puzzle_stats.c`, `tests/test_puzzle_stats.c`.

- [ ] **Step 1: Tests:**
  - `puzzle_rating_after(1500, 0, 1500, 1) == 1520`, `(1500, 0, 1500, 0) == 1480`, `(1500, 25, 1500, 1) == 1510`, and `(410, 30, 2000, 0) == 400` (the floor).
  - `puzzle_stats_record`:
    - a solve raises `played`, `streak`, `best_streak` and `seen`;
    - a fail resets `streak` and appends to `missed` once only, even when it fails again;
    - a solve of a missed puzzle removes it;
    - `puzzle_stats_forgive` removes a missed puzzle without touching the rating or streak.
  - `puzzle_pick` with seed 1:
    - it returns an unseen puzzle within ±100 of 1500;
    - with every puzzle within ±300 marked seen, it returns one further out;
    - with all puzzles seen, it resets `seen` and returns one;
    - `themes = TH_FORK` returns only forks;
    - with every fork seen, it resets only the forks.
  - Storage in a `mkdtemp` dir:
    - a save/load round trip (rating, streaks, rush_best, seen, missed in order);
    - a missing file gives defaults and returns 0;
    - a file with a garbage line and an unknown id loads the rest;
    - rename moves the file;
    - remove deletes it;
    - a profile name with `/` or `..` is refused (returns 0).
- [ ] **Step 2:** Run it. Expected: a link failure.
- [ ] **Step 3:** Implement per the spec:
  - Elo as `round(K * (score - 1/(1+10^((pr-r)/400))))`, with K 40 while `played < 20`, else 20, and a floor of 400;
  - `puzzle_pick` widens by 100 up to 3000; on exhaustion it clears `seen` for the matching subset and retries; it returns −1 only if no puzzle matches `themes`;
  - the file holds `key value` lines, with the ids space-separated on the `seen` and `missed` lines, written through `.tmp` + `rename`.
- [ ] **Step 4:** Run `make -B test`. Commit `feat(puzzles): rating, selection and the profile's puzzle file`.
