# Profiles and Launcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Profiles, a PGN game database, `resign`, and a full-screen launcher that replaces the start menu.

**Architecture:** Core modules `game/records.c` (the `games.pgn` database) and `game/profiles.c` (`profiles.conf`, first run), both unit-tested. The TUI records games, remembers settings, and gets `launcher.c`.

**Tech Stack:** C, ncursesw, `make test`.

**Spec:** `docs/superpowers/specs/2026-09-26-profiles-design.md`

> Terse by request. Core tasks carry headers and tests as code; implementation and TUI steps are imperative lines. The spec holds every value.

## Global Constraints

- Zero warnings under `-O2 -Wall`. After a header change, build with `make -B`.
- Core (`src/game`, `src/utils`) never includes ncurses.
- Sparse comments. No attribution trailers in commits.
- Paths:
  - profiles: `$XDG_CONFIG_HOME/dchess/profiles.conf`, else `~/.config/dchess/profiles.conf`;
  - games: `~/.local/share/dchess/games.pgn`.
- Limits: 32 profiles, names 1–24 characters.
- Reserved names: `easy`, `medium`, `hard`, `human`, `guest` (case-insensitive). No `[`, `]` or `;`; no leading or trailing space; no clash with an engine name.
- Tags and values exactly as the spec's table.

## Review Focus

1. **A profile name with spaces or unicode** round-trips through `profiles.conf`, PGN tags and rename. Test: Task 2, `test_rename_spaces`; Task 4, a name with a space.
2. **A `games.pgn` edited or damaged by hand** (missing blank line, stray text) still loads its good games. Test: Task 2, `test_damaged`.
3. **Deleting the active profile** makes another active, and the last one can't be deleted. Test: Task 4.
4. **The `$USER` name is invalid** (e.g. `root;x`, or empty) → falls back to `player`. Test: Task 4.
5. **The launcher on a terminal smaller than 80×20** hides the side panels and `p` cycles profiles. Checked with tmux in Task 7.

### Task 2: Game database (`records.c`)

**Files:** `headers/game/records.h`, `src/game/records.c`, `tests/test_records.c`

**Note:** until Task 3 renames it, the field is `Player.engine`. Task 2 uses `p->engine`, and Task 3's rename carries it.

- [ ] **Step 1: Header**, `headers/game/records.h`:

```c
#ifndef RECORDS_H
#define RECORDS_H
#include "game/game.h"
#include "game/players.h"
#include "utils/engines.h"
#include "utils/stats.h"

typedef enum { KIND_PROFILE, KIND_GUEST, KIND_DCHESS, KIND_ENGINE } SideKind;

typedef struct {
    char     date[11], time[9];
    char     white[48], black[48];
    SideKind white_kind, black_kind;
    char     white_strength[32], black_strength[32];
    int      result;          /* 1 white won, 0 draw, -1 black won */
    char     end_reason[16];
    int      plies, seconds, legacy;
} Record;

typedef struct { Record *r; int count, cap; } RecordList;
typedef struct { int games, wins, draws, losses; } RecordTally;

int  records_path(char *buf, size_t n);
/* "checkmate", "stalemate", "material", "fifty-move", "repetition", "resigned" */
const char *records_end_reason(const char *result_text);
int  records_append(const char *path, const GameState *g, const Player p[2],
                    const EngineList *engines);
int  records_append_legacy(const char *path, const char *profile, long timestamp, int result);
int  records_load(const char *path, RecordList *out);   /* 0 if missing; skips bad games */
void records_free(RecordList *l);
int  records_rename(const char *path, const char *old_name, const char *new_name);

/* Legacy records are excluded; add the profile's legacy line yourself. */
RecordTally records_tally(const RecordList *l, const char *who);
int  records_recent(const RecordList *l, const char *who, const Record **out, int max);
int  records_winrate(const RecordList *l, const char *who, float *out, int max);
void records_to_stats(const RecordList *l, const char *who, DchessStats *out);
#endif
```

- [ ] **Step 2: Test**, `tests/test_records.c`, using a temp dir and `path = dir/games.pgn`. Helpers `play()`, `mate()` (fool's mate), `P(kind,name)`. Cases:
  - **round trip:** a profile `saeed` vs engine `Fake` (registry with one entry, time 1000 → strength `1s/move`) after fool's mate:
    - `records_append` returns 1;
    - `records_load` gives count 1;
    - `white`=`saeed`, `black_kind`=`KIND_ENGINE`, `black_strength`=`1s/move`, `result` = -1, `end_reason`=`checkmate`, `plies` = 4, and `date` has length 10.
  - **FEN start:** the record loads, and the file contains `[SetUp "1"]`.
  - **tally:** games with `saeed` vs `alice` (both profiles, White wins), a Guest vs `saeed` draw, and dchess vs dchess (not appended by the caller).
    - `tally(saeed)` = {2, 1, 1, 0}; `tally(alice)` = {1, 0, 0, 1}.
    - `tally("Guest")`.games = 0: guest names never match.
  - **resigned:** set `g.game_over` = 1 and result `"White resigns — Black wins"` → `end_reason` `resigned`, `result` -1.
  - **legacy:** `records_append_legacy(path,"saeed",t,1)` ×3 (+1, −1, 0) → `tally` unchanged, `records_winrate(..., 30)` returns 3 values plus the others, and `recent` skips none (legacy entries show).
  - **`test_rename_spaces`:** `saeed` → `Sa Eed`. Profile-kind tags change. An engine named `saeed` in another game keeps its name (it's written with `BlackKind "engine"`). `tally("Sa Eed")` equals the old tally.
  - **`test_damaged`:** an empty file → 0 records. A file = one good game + `"garbage\n[White \"x\"\n"` + one good game → 2 records.
  - **missing file:** `records_load` returns 0, count 0.
  - **speed:** append 5000 games, then `records_load` takes under 500 ms.
  - **`records_to_stats`:** for `saeed` over a mix including dchess Hard → `games_played[2]` = 1, and totals and colour split correct.
- [ ] **Step 3:** `make build/test_records`. Expected: `records.h` not found.
- [ ] **Step 4: Implement** `src/game/records.c`:
  - `records_path`: HOME-based, and mkdir `.local/share/dchess` like `stats.c`.
  - `records_end_reason`: `strstr` on `Checkmate`, `Stalemate`, `Insufficient`, `50-move`, `repetition` and `resigns`; else `""`.
  - **`records_append`:**
    - Kinds come from each `Player`: human with a name → profile; human without → guest; built-in → dchess; UCI → engine.
    - Strength: `players_level_name` for dchess; `engine_strength_label(engines_find(...))` for an engine.
    - Tags: `Time` from `time()`; `PlyCount` = `move_count - log_start`; `Seconds` = `white_clock + black_clock`; `EndReason` from `records_end_reason(g->result)`.
    - Names via `players_pgn_name`. Humans with a profile emit the name; Guest emits `Guest`, or `Player 1`/`Player 2` when both are guests.
    - Write through `pgn_append`.
  - `records_append_legacy`: write tags only, with an empty movetext line holding the result token. `Date`/`Time` from the timestamp, `Black "dchess"`, `BlackKind "dchess"`, `EndReason "legacy"`, `PlyCount "0"`.
  - **`records_load`:**
    - Read lines. `[Key "Value"]` fills the current record; a `[Event` line starts a new one, and the previous one is kept if it had `White`, `Black` and `Result`.
    - Skip non-tag lines. `legacy` = end reason `legacy`.
    - Grow `r` by doubling.
  - **`records_rename`:**
    - Stream to `path.tmp`. Buffer each game's tag lines; replace the `White`/`Black` value equal to `old_name` only when the game's matching `*Kind` is `profile`.
    - Then `rename()`.
  - **tally/recent/winrate:**
    - A record belongs to `who` when a profile-kind side name equals `who`.
    - Win/loss comes from that side.
    - `recent` goes newest first; `winrate[i]` = wins ÷ games over the belonging games up to i (rolling), oldest first, the last `max` values.
  - **`records_to_stats`:**
    - zero `out`;
    - dchess opponents fill the per-level counters (via the strength word);
    - every game fills the totals and colour split;
    - history = the last 256 belonging games (timestamp from date/time, result from that side).
- [ ] **Step 5:** `./build/test_records` passes, then run `make -B test`.
- [ ] **Step 6:** `git commit -m "feat: PGN game database for finished games"`.

- [ ] **Step 1: Header:**

```c
#ifndef PROFILES_H
#define PROFILES_H
#include "utils/engines.h"
#include "utils/stats.h"
#define PROFILES_MAX 32
#define PROFILE_NAME_MAX 24
typedef struct {
    char name[PROFILE_NAME_MAX + 1];
    char theme[24], white[48], black[48];
    int  legacy_games, legacy_wins, legacy_losses, legacy_draws;
} Profile;
typedef struct { Profile p[PROFILES_MAX]; int count, active; } ProfileList;

int  profiles_path(char *buf, size_t n);
int  profiles_load(ProfileList *l);            /* 0 if the file does not exist */
int  profiles_save(const ProfileList *l);      /* via .tmp + rename */
int  profiles_check_name(const ProfileList *l, const EngineList *e, const char *name,
                         int skip, char *err, size_t n);
int  profiles_add(ProfileList *l, const EngineList *e, const char *name, char *err, size_t n);
/* Also relabels the profile's games in `games`. */
int  profiles_rename(ProfileList *l, const EngineList *e, int i, const char *name,
                     const char *games, char *err, size_t n);
int  profiles_remove(ProfileList *l, int i);   /* 0 for the last profile */
int  profiles_find(const ProfileList *l, const char *name);
/* Names with the active one first, for players_apply_command. */
int  profiles_names(const ProfileList *l, const char **out, int max);
/* No profiles.conf yet: create `user` (or "player"), import `old`, save. */
int  profiles_first_run(ProfileList *l, const char *user, const DchessStats *old,
                        const char *games);
#endif
```
