## Review Focus

1. **Promotion by cursor while an engine is thinking, or with the game over:** the picker never appears; Enter behaves as before. Task 1 smoke test.
2. **Esc at the promotion prompt:** the move is cancelled and nothing is played; the next Enter starts a new selection. Task 1 smoke test.
3. **Rush's 700 ms pause:** it doesn't eat keys or run the clock past zero; a key pressed during the pause is not lost as a move. Task 2 smoke test.
4. **genfens against a hanging engine:** the game ends within `--hang-ms`, and the engine process is freed (no zombie pile-up across games). Task 3 test.
5. **The PVS-gated PV rule:** the analysis test stays green (40 runs) and `test_search` passes. Task 3.
