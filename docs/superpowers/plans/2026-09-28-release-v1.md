# Release v1.0.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** v1.0.0 that installs cleanly, with a man page, a changelog, CI and an AUR package.

**Architecture:**
- The version is defined once, in `version.h`.
- The Makefile gains `install`, `uninstall` and `CFLAGS_EXTRA`.
- Two shell tests join `make test`.
- CI is a single workflow file; the AUR files sit in `packaging/aur/`.

**Tech Stack:** make, sh, roff, GitHub Actions, makepkg.

**Spec:** `docs/superpowers/specs/2026-09-28-release-v1-design.md`

> Terse by request.

## Global Constraints

- Zero warnings; no attribution anywhere, including the CHANGELOG, the PKGBUILD and the release notes.
- `make install` never touches `~/.config/dchess` or `~/.local/share/dchess`.
- The tag and the GitHub release happen only after the owner merges the PR.

## Review Focus

1. **`make install` with no `PREFIX` and no root:** it fails with a clear permission error rather than a half-install. With `DESTDIR` set, it installs under that directory. Task 2 test.
2. **`make uninstall` after a PREFIX change, or with the files missing:** no error for files already gone, and nothing else is removed. Task 2 test.
3. **The man page on a system without groff:** the test skips the render check and still checks the options. Task 2.
4. **CI on a clean Ubuntu:** the tests needing a terminal or Stockfish are absent or skipped. `test_genfens` uses only `fake_uci`. Task 3 (the first CI run on the PR).
5. **The PKGBUILD `check()`:** `make test` runs in a clean chroot-like build with no `$HOME` config. Task 4 `makepkg`.

### Task 2: Install, uninstall, the man page

**Files:** Create `docs/dchess.6`, `tests/test_install.sh` and `tests/test_manpage.sh`. Modify the `Makefile`.

- [ ] **Step 1: Tests.**
  - `test_install.sh`:
    1. `D=$(mktemp -d)`, then `make install DESTDIR=$D PREFIX=/usr`;
    2. check `$D/usr/bin/dchess` is executable, and that `$D/usr/share/man/man6/dchess.6` contains `1.0.0` and no `@VERSION@`;
    3. check `$D/usr/share/doc/dchess/{README.md,guide.md,CHANGELOG.md}` and `$D/usr/share/licenses/dchess/LICENSE` exist;
    4. check `$D/usr/bin/dchess --version` prints `dchess 1.0.0`;
    5. run `make uninstall DESTDIR=$D PREFIX=/usr` and check `find $D -type f` is empty;
    6. run `make uninstall` again, which exits 0;
    7. `rm -rf $D`.

    The script prints `All install tests passed.` or exits 1.
  - `test_manpage.sh`:
    - every `--[a-z-]+` in `./dchess --help` appears in `docs/dchess.6` (escaped as `\-\-name`);
    - if `groff` exists, `groff -man -Tutf8 -ww docs/dchess.6 >/dev/null` gives no warnings on stderr.

  Makefile `test`: run both scripts after the C suites (they need `dchess` built, so add `$(TARGET)` as a prerequisite). Run `make test`; expected FAIL (no install target, no man page).
- [ ] **Step 2: Makefile.**
  - `PREFIX ?= /usr/local`, `DESTDIR ?=`, `CFLAGS_EXTRA ?=` (appended to `CFLAGS`), and the `VERSION` read from `version.h` with `sed`;
  - `install: $(TARGET)` uses `install -Dm755` / `-Dm644`, with the man page through `sed s/@VERSION@/$(VERSION)/`;
  - `uninstall` runs `rm -f` on each file, then `rmdir` on the doc and license directories, ignoring failures;
  - `.PHONY` updated.
- [ ] **Step 3:** Write `docs/dchess.6` per the spec's sections, from `--help`, README Controls and the guide's Files section. Also create a first `CHANGELOG.md` stub (Task 3 fills it), so the install test finds it.
- [ ] **Step 4:** Run `make -B test` (all green), then commit `feat(build): make install/uninstall and a man page`.

### Task 4: The AUR package

**Files:** `packaging/aur/PKGBUILD` and `packaging/aur/.SRCINFO`.

- [ ] **Step 1:** Write the PKGBUILD:
  - `pkgname=dchess`, `pkgver=1.0.0`, `pkgrel=1`;
  - `arch=(x86_64 aarch64)`, `license=(MIT)`, `depends=(ncurses)`, `makedepends=(gcc make)`;
  - `source=("$pkgname-$pkgver.tar.gz::https://github.com/DDumbying/dchess/archive/refs/tags/v$pkgver.tar.gz")`, `sha256sums=('SKIP')`;
  - `build()` runs `make`; `check()` runs `make test`; `package()` runs `make PREFIX=/usr DESTDIR="$pkgdir" install`.
- [ ] **Step 2:** Local check, if `makepkg` exists: a temporary copy whose `source` points at `git+file://$PWD#branch=release/v1.0.0`, then `makepkg -f --noconfirm` (no install), and inspect the package's file list with `tar tf`. Generate `.SRCINFO` with `makepkg --printsrcinfo` from the real PKGBUILD. Commit `feat(packaging): an AUR PKGBUILD`.
